 # زاد المسلم

منظومة إسلامية عربية متجاوبة، تبدأ بواجهة ويب قابلة للتثبيت كتطبيق PWA.

## التشغيل
افتح `index.html` عبر خادم محلي أو انشر المستودع على GitHub Pages. يدعم الموقع البحث، التصنيف، الترقيم، الوضع الليلي، والمفضلة محليًا.

## تنبيه المحتوى
هذه الواجهة هي الأساس التقني. يجب إضافة النصوص القرآنية والأحاديث والأذكار من مصادر موثوقة مع توثيقها قبل النشر العام.
